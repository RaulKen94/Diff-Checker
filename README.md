# 🔍 Diff Checker `v1.3.0`

A lightweight, high-performance, single-file HTML web application designed for fast, secure, and intuitive text/code diff analysis directly in your browser.

![Version](https://img.shields.io/badge/version-1.3.0-blue.svg)
[![License](https://img.shields.io/badge/License-Apache_2.0-orange.svg)](https://opensource.org/licenses/Apache-2.0)
![Dependencies](https://img.shields.io/badge/dependencies-zero--install-brightgreen.svg)

---

## ✨ Features

- **⚡ Real-Time Comparison**: Computes line-by-line and word-level diffs instantaneously as you type or paste text.
- **👁️ Dual Viewing Modes**:
  - **Split View**: Side-by-side layout with synchronized scrolling.
  - **Unified View**: Inline mono-window format ideal for code reviews.
- **🖥️ Dedicated Fullscreen Mode**: Expand the diff output to full screen (automatically switches to unified view with full diff highlighting for maximum readability). Exit via the on-screen button or pressing `ESC`.
- **🚀 Fast Scroll Controls**:
  - **Top (Cima)**: Instantly scrolls to top and highlights the first difference.
  - **Middle (Metà)**: Scrolls smoothly to the vertical midpoint.
  - **Bottom (Fine)**: Instantly scrolls to bottom and highlights the last difference.
- **🎯 Diff Navigation**: Jump forward and backward through individual changes using `<` and `>` controls.
- **📊 Independent Input Windows**:
  - Real-time line counter for Original (File A) and Modified (File B).
  - One-click **Copy** and **Clear** controls for each editor.
  - File drag-and-drop & file picker support.
- **🔒 Privacy First & In-Memory**: Zero local storage footprint. No cookies or local cached data — everything processes purely in browser RAM.
- **📦 Monolithic HTML**: Single self-contained `index.html` file with no build steps or local backend server required.

---

## 🚀 Quick Start

1. Download or clone `index.html`.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Paste or drop your files into **File A** (Original) and **File B** (Modified) to view the real-time diff.

---

## 🛠️ Built With

- **HTML5 & Vanilla JS**
- **Tailwind CSS** (via CDN for sleek, responsive UI styling)
- **jsdiff** (Client-side diffing engine)

# 🔍 Diff Checker `v1.3.0`

Un'applicazione web leggera, performante e in un unico file HTML monolitico, progettata per il confronto rapido e sicuro di testo e codice direttamente all'interno del browser.

![Versione](https://img.shields.io/badge/versione-1.3.0-blue.svg)

## ✨ Caratteristiche Principali

- **⚡ Confronto in Tempo Reale**: Calcola e aggiorna le differenze riga per riga e parola per parola mentre digiti o incolli il testo.
- **👁️ Doppia Modalità di Visualizzazione**:
  - **Affiancato (Split View)**: Layout a due colonne con scorrimento sincronizzato.
  - **Unificato (Unified View)**: Vista mono-finestra ideale per la revisione rapida del codice.
- **🖥️ Modalità Schermo Intero**: Espandi il risultato del diff a schermo intero (passa automaticamente alla vista unificata evidenziando le differenze per la massima leggibilità). Esci con il pulsante dedicato o premendo `ESC`.
- **🚀 Scorciatoie di Scorrimento Rapido**:
  - **Cima**: Scorre all'inizio del documento ed evidenzia il primo diff.
  - **Metà**: Scorre al centro del pannello.
  - **Fine**: Scorre alla fine del documento ed evidenzia l'ultimo diff.
- **🎯 Navigazione per Diff**: Salta rapidamente alla modifica precedente o successiva con i pulsanti `<` e `>`.
- **📊 Finestre di Input Indipendenti**:
  - Contatore dinamico delle righe in tempo reale per File Originale (A) e Modificato (B).
  - Pulsanti dedicati per **Copia** e **Svuota** per ciascuna finestra.
  - Supporto al caricamento file e Drag & Drop.
- **🔒 Massima Privacy (In-Memory)**: Nessun salvataggio in `localStorage`, cookie o server remoti. Tutto l'elaborato risiede esclusivamente nella memoria RAM del browser.
- **📦 HTML Monolitico**: File singolo `index.html` che non richiede installazione, compilazione o server di backend.

---

## 🚀 Guida Rapida

1. Scarica o clona il file `index.html`.
2. Apri `index.html` in un qualsiasi browser web (Chrome, Firefox, Safari, Edge).
3. Incolla o trascina i tuoi file nei riquadri **File A** (Originale) e **File B** (Modificato) per analizzare le differenze in tempo reale.

---

## 🛠️ Tecnologie Utilizzate

- **HTML5 & Vanilla JS**
- **Tailwind CSS** (tramite CDN per un'interfaccia moderna e reattiva)
- **jsdiff** (Libreria client-side per il calcolo delle differenze)
